# neuroflow

Link to full documentation: https://neurocog-mobility.github.io/neuroflow/

## Installation

Run the following from a terminal:

```
pip install git+https://github.com/neurocog-mobility/neuroflow.git
```

## Usage

### Command-Line Interface (CLI)
Open a terminal and run ```neuroflow --help``` to view all available CLI commands.
For details on how to run a command, use ```neuroflow <command> --help```.

### Graphical User Interface (GUI)
Open a terminal and run ```neuroflow gui``` to launch the GUI. See the [tutorials](https://neurocog-mobility.github.io/neuroflow/tutorials/) for detailed usage information.
