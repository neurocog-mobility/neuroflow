Git setup
=====================

Git is a version control system that tracks changes to files,
enabling collaboration, history management, and efficient software development.
Some Python packages are only hosted on GitHub and so NeuroFlow requires a Git
installation in order to access those packages. A GitHub account is **not** required.

Downloading Git
-----------------------

Start by downloading the official installer for your system:

1. Navigate to the official Git downloads page, and select your system: |git_link|.

2. 

    * **Mac/Linux**: Follow the instructions provided on the Git website to install using your system's package manager

    * **Windows**:

        1. Download the standalone installer for your system.

        2. Double-click on the downloaded installer (and accept to run with administrator privileges if applicable)

        3. Leave the default options selected, click "Install", and exit the installer once complete.
