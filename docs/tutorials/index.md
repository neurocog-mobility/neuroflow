# Tutorials

This section provides hands-on, step-by-step guides to help you learn how to use NeuroFlow in your own projects.

These tutorials cover both executing built-in analysis workflows as well as custom analyses.

Browse the tutorials below to find the one that suits your needs.

## NeuroFlow GUI
- [Gait analysis](tutorial-cwa.md): Analyzing IMU data from an Axivity sensor.
- [HRV analysis](tutorial-ecg.md): Analyzing ECG data from a Bittium sensor.
- [Streaming free-living data](tutorial-freeliving.md): Streaming and analyzing data from long, continuous free-living data files.

## Scripting with NeuroFlow
- [Custom HRV analysis](tutorial-custom-ecg): Analyzing windowed ECG data around given medication timestamps.
