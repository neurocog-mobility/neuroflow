Running your first NeuroFlow project
======================================

This tutorial will walk through how to create a new NeuroFlow project and start processing experimental data.

For the tutorial project, we will process a sample data collection where subjects walked with a set of accelerometers
worn on the waist and ankles. Since the data was collected continuously, timestamps were also 
recorded to mark the start/end of each walking trial.

**Goal**: Extract the trial data from each session, then detect the steps and produce a step summary report.
